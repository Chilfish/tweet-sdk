# 开发日志

按日期记录当天完成的工作，文件名 `YYYY-MM-DD.md`。

## 何时写

- 不属于「三类必写文档」（公开契约 / 构建发布 / 事故修复）的改动。
- 决策过程、排查过程、被否决的方案。
- 大改动的中间状态，方便下次接续。

## 格式

```md
# 2026-11-18

## 完成

- 迁移到 tsdown + bun
- 新增 docs 体系与 check:docs 门禁

## 决策

- 发布不走 NPM_TOKEN：改用 OIDC，减少长期凭据

## 待办

- 补充 examples/api 场景
- 评估是否需要 changesets
```

## 约定

- 日志不参与门禁，不必追求完整。
- 涉及公开契约或事故的内容同时写入正式文档，日志只做指针。
- 本目录不在 `docs/README.md` 逐篇登记（`check-docs` 已豁免）。
