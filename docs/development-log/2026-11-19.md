## 决策

- 不导出旧 `Rettiwt` 门面：它绑定 `RettiwtConfig` 与 axios 形态，保留会把耦合带回公开面。
- `buildXShellHeaders` 仍接收 base64 apiKey；`TidProvider` 内部接收已解码 cookie，避免 core 依赖 `AuthService`。
- `./react` 与 `package.json#exports["./react"]` 留到 Phase 3，避免声明不存在的产物。
- `undici` 只允许在 `./node` 中懒加载；core 默认 `fetch`，Workers / Deno / Bun / 浏览器零改动。
- SOCKS 代理暂不支持：fetch 传输层的 `ProxyAgent` 只接受 `http(s)://`，`createProxyFetch` 会给出明确错误。
